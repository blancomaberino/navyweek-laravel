## Headline finding

Fashion Nova runs an **official, verification-gated military discount: 30% off** for **military and veterans**, delivered through **VerifyPass** (the merchant-contracted verification widget, not a coupon aggregator). You verify your status through VerifyPass, receive a single-use code, and apply it in the discount box at checkout on fashionnova.com. This is a real brand-run offer — but Fashion Nova's business model is a **near-constant public promo-code firehose** (site-wide codes of 30–50%+ run almost continuously), so the military 30% is frequently **matched or beaten by a stackable-free public code**, and it typically **can't be combined** with other codes. Archetype: **verified % that competes with the brand's own perpetual sitewide sales — verify, then compare against today's public code before you use the gated one.** The honest verdict: use the VerifyPass 30% only when it beats the current public promo; often the public code wins and needs no verification.

## Stacking Rules (verified, both brand + portal terms)
1. Fashion Nova checkout accepts **one discount code per order** — the VerifyPass military code and a public promo code **cannot be combined**.
2. **Cashback portals** (Rakuten, etc.) pay on the post-code total and are the only reliable "stack" on top of either code.
3. Military code is **single-use**; re-verify through VerifyPass for a new code.
4. Sale/markdown eligibility for codes varies by campaign — some public codes exclude already-discounted items; verify at cart.
