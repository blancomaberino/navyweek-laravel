# Carter's — Military Discount & Maximum-Savings Brief

**Researched:** July 11, 2026 · **Baseline cart for all math:** one $60 kids'/baby apparel cart at carters.com.

## Headline finding

Carter's does **not publish a fixed-percentage military discount** on its own site, and the numbers coupon aggregators cite ("10–25%," "20%," "75–85%") are fabricated and contradict each other. Carter's official pricing terms only reference "special military discounts" in a fine-print exclusion (they can't be combined with coupons or Grandparent Wednesdays) — the amount, eligibility, and verification path are **not documented on the primary source.** ID.me explicitly confirms Carter's does **not** use ID.me (you'd "verify directly with Carter's"), and Carter's is **not** on GovX (the GovX "carter" listing is an unrelated brand, "Fifth and Ninth"). The one concrete, verifiable military benefit is **free shipping on orders $35+ shipped to APO/FPO addresses.** Archetype: **H (myth brand)** — the everyday value is the loyalty wallet + Carter's famously deep, frequent sitewide sales, not a blanket military %; secondary **J (vague/unofficial)**. Best path for a service member: **skip the phantom military %** and stack a public 50–60% sitewide sale (or Buy 1 Get 2 Free) with a 20% signup/sitewide code, Carter's Rewards points, and a cashback portal.

## Stacking Rules (verified, both brand + portal terms)
1. **Coupon codes don't combine** with each other, with Grandparent Wednesdays, or with "special military discounts" — Carter's official pricing terms state this explicitly. You pick one code per order.
2. **Codes are excluded on clearance, doorbusters, and Treasure Box** items — the deepest markdowns are already "final," so a code usually can't go deeper there.
3. **Cashback vs. coupon:** a coupon-code order commonly reduces or voids Rakuten/TopCashback. A *sitewide sale with no code entered* is portal-safe; a scraped "military code" is exactly what breaks tracking. Don't assume code + cashback stack.
4. **Rewards points stack on everything** — you earn 1 pt/$1 (VIP 2 pt/$1) regardless of sale or code; points are the one reliable "always-on" layer.
5. **No verified military-% stack exists** — because no military % is published, there is nothing to combine; treat APO/FPO free shipping as the only military-specific benefit.

#### Does Carter's run a Veterans Day or Memorial Day sale?
