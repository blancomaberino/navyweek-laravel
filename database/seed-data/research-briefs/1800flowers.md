# 1-800-Flowers — Military Discount & Maximum-Savings Brief

**Researched:** July 15, 2026 · **Baseline cart for all math:** one ~$60 flower/gift order (a common mid-tier bouquet before shipping/service fees — the unit most readers compare).

## Headline finding

**1-800-Flowers does offer real, published military/veteran discounts — but through two different channels with very different value, and neither is automatically the best deal.** The broadly-available offer is **15% off sitewide (and 20% off select collections) with promo code `MILITARYUSA`** for Active Duty, Military Retirees, Veterans, Reserve/National Guard, and dependents. The deeper offer is reserved for **WeSalute** (formerly Veterans Advantage) members: **30% off for WeSalute+ members (code `VETERAN4`)** and **25% for WeSalute Basic members (code `VETERAN3`)**, each requiring a valid WeSalute Member ID — and WeSalute+ is a **paid membership**, so the 30% only pencils out for frequent/large orders.

The catch that decides the whole page: **1-800-Flowers runs frequent public promo codes (commonly 20–40% off) and only lets you use one promo code per order.** So the free `MILITARYUSA` 15% sitewide is *routinely matched or beaten by a public code anyone can use* — meaning for most single orders the military code is not your best move. Archetype: **E (multi-tier identity discount)** with an **I-like paid-membership upgrade tier** (WeSalute+). Ignore aggregator pages inventing a "40% off military code" — the verified codes are the four above.

## Stacking Rules (verified, both brand + portal terms)
1. **One promo code per order.** The military code and any public code occupy the same single checkout field — they do **not** stack. Pick the deeper one.
2. **WeSalute codes require a Member ID.** `VETERAN4`/`VETERAN3` won't apply without a valid WeSalute membership number; `VETERAN4`'s 30% specifically requires the **paid WeSalute+** tier.
3. **ID.me Shop cash back is a separate rebate layer**, not a code — and cash-back portals commonly void on coupon-code orders, so don't assume "military code + cash back." Treat cash back as the play only on a *no-code* full-price order.
4. **Shipping + service fees are not removed by any code** — factor them into the real total.
5. **The discount spans the family of brands** for WeSalute members (Harry & David, Cheryl's Cookies, Shari's Berries, FruitBouquets), which is where WeSalute+ 30% earns its keep.

### Who Qualifies
- **Active duty** — eligible for `MILITARYUSA`; eligible for WeSalute codes with a WeSalute membership.
- **Veterans & retirees** — eligible for `MILITARYUSA` and WeSalute codes.
- **Reserve / National Guard** — eligible.
- **Military spouses / dependents / immediate family** — eligible via the military-community and WeSalute offers (WeSalute extends to spouses, parents, children).
- **First responders / teachers / nurses / students** — no dedicated 1-800-Flowers program found; use public codes.

### How To Redeem Online
1. Add your arrangement/gift to cart.
2. At checkout, enter the code that gives you the deeper discount: `MILITARYUSA` (15% / 20% select) or your WeSalute code (`VETERAN3` 25% / `VETERAN4` 30%) with your WeSalute Member ID.
3. Only one code applies — compare against any live public sale code first.
4. Note the separate shipping + service fee, which no code removes.

### How To Redeem By Phone (WeSalute)
1. Call 1-800-Flowers' order line.
2. Provide the WeSalute promo code and your WeSalute+ Member ID.
3. The 30%/25% is applied to eligible items across the family of brands.

### How Verification Works
For the WeSalute offers, you must be a **WeSalute member** and supply your **Member ID** — WeSalute+ (the 30% tier) is a paid membership. The `MILITARYUSA` code is the military-community offer entered directly at checkout. Separately, **ID.me Shop** lists 1-800-Flowers for **cash back** (a rebate, not a code) — that's a different mechanism and generally won't combine with a promo code.

### Exclusions And Fine Print
- One promo code per order; military and public codes don't stack.
- Shipping and service fees are added on most orders and aren't discounted by codes.
- WeSalute codes require a valid membership/Member ID; WeSalute+ (30%) is paid.
- Peak floral holidays (Valentine's, Mother's Day) may carry surcharges that reduce the effective discount.

### Best Ways To Save More
- **Compare the military code against the live public code** every time — use the deeper one.
- **WeSalute+ 30%** if you gift frequently across the family of brands.
- **ID.me Shop cash back** on a no-code full-price order.
- **Passport free-shipping membership** (public) can beat per-order shipping fees for frequent senders — separate from the discount codes.

### FAQ

#### Does 1-800-Flowers offer a military discount?
Yes. Use promo code `MILITARYUSA` for 15% off sitewide (20% off select collections) if you're Active Duty, a Retiree, Veteran, Reserve/National Guard, or a dependent. WeSalute members can get 25% (`VETERAN3`) or 30% (`VETERAN4`, paid WeSalute+ tier) with a Member ID.

#### How much is the 1-800-Flowers military discount?
15% sitewide / 20% on select collections with `MILITARYUSA`; 25% or 30% through WeSalute. The 30% requires a paid WeSalute+ membership.

#### Do veterans, spouses, and dependents qualify?
Yes — the offers cover active duty, veterans, retirees, Guard/Reserve, and immediate family (WeSalute extends to spouses, parents, and children).

#### How do I verify my status?
For WeSalute codes you supply a WeSalute Member ID (WeSalute+ is paid). `MILITARYUSA` is entered directly at checkout as the military-community code.

#### Does 1-800-Flowers use ID.me, GovX, SheerID, or WeSalute?
WeSalute is the named partner for the 25%/30% codes. ID.me Shop separately lists 1-800-Flowers for cash back (a rebate, not the discount code).

#### Can I use it online or by phone?
Online at 1800flowers.com and the family brands; WeSalute offers can also be redeemed by phone with your Member ID.

#### Can I combine the military discount with a public promo code?
No — 1-800-Flowers allows one promo code per order. Use whichever single code is deeper.

#### What's actually the cheapest way for a service member to buy from 1-800-Flowers?
Check the live public sale code and compare it to `MILITARYUSA` 15%; use the deeper one (they don't stack). If you order often across Harry & David, Cheryl's, etc., paid WeSalute+ 30% (`VETERAN4`) is usually the best standing rate.

#### Does 1-800-Flowers offer a first responder, teacher, nurse, or student discount?
No dedicated program was found for those groups — use the rotating public codes.
