# Montana Knife Company — Military Discount & Maximum-Savings Brief

**Researched:** July 20, 2026 · **Baseline cart for all math:** one $300 fixed-blade knife order (MKC production knives typically run ~$200–$450), shipped to a US address.

## Headline finding

Montana Knife Company (MKC) offers a real, **official military/first-responder discount, verified through GovX ID** — a persistent partnership advertised on MKC's own `/pages/govx-id-military-discount` page. Military.com lists the benefit as "**Save up to 20%**," but GovX gates the exact live percentage behind verification (it is revealed only after you log in / verify), so the public-facing number is a range, not a fixed figure. The single best savings path for most eligible shoppers is the GovX ID discount applied at checkout; MKC does not stack codes, and its biggest public price breaks come from the periodic **MKC Expo pricing** and blemished/second sales rather than from any coupon. There is no ID.me, SheerID, or WeSalute path — GovX is the sole verification provider.

## Stacking Rules (verified)
1. **No code stacking.** MKC issues one discount code slot per order; the GovX military code cannot be combined with a referral or promo code. (MKC GovX page.)
2. **Free shipping is automatic at $200+** and applies even with a discount code — so the GovX discount does not cost you free shipping.
3. **Drops sell out fast.** MKC advises having your GovX discount ready before knife-drop times; if a model sells out, no discount can be applied retroactively.
4. **Referral 15% is first-order only** and is a separate mechanic from the military discount — you cannot use both.
