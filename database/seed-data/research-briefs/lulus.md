# Lulus — Military Discount & Maximum-Savings Brief

**Researched:** July 18, 2026 · **Baseline cart for all math:** one $120 full-price women's dress-and-accessories order on Lulus.com (US, online only).

## Headline finding

Lulus (women's fashion/dresses, Lulus.com) offers a real, official **10% off** military discount, verified through **The Beans Group** (its consumer service is branded **Beans iD**, from Student Beans / Pion). It is an **online-only** offer — valid on Lulus.com or the Lulus app — with **no minimum purchase**, but it **cannot be combined with any other offer** and it excludes gift cards, beauty & wellness items, and previous purchases. Lulus does **not** use ID.me or SheerID for this offer, and there is **no in-store military discount** (Lulus is direct-to-consumer online), so aggregator claims of "show your military ID at a local Lulus store" or "up to 25% off" are false. Archetype: **apparel DTC brand with a flat single-tier verified discount (10%) layered over a heavy public promo cadence (15%-off-first-order text signup, archive/sale markdowns).** The honest best-value catch: because the 10% cannot stack with anything, a first-time shopper is usually better off taking Lulus's own **15% off first order via text signup** than the 10% military code; the 10% military code wins mainly on **repeat, full-price orders**, ideally with a cashback portal layered on top (portals pay a separate rebate).

## Stacking Rules (verified, both brand + portal terms)
1. The 10% military code **cannot be combined with any other offer** — no stacking with promo codes, the 15% text-signup code, or other discounts. You use one Lulus offer per order. (Source: Lulus terms.)
2. Each Beans iD code is **valid for one-time use only** and is **not transferable** — only valid for the Beans iD account holder it was issued to. (Source: Lulus terms.)
3. The code **excludes gift cards, beauty & wellness items, and previous purchases**, and is **US-only**. There is **no minimum purchase**. (Source: Lulus terms.)
4. **Cashback portals are separate** — a portal rebate (Rakuten/TopCashback) is paid by the portal, not Lulus, so in principle it applies on top of whichever single Lulus code you use. Standard caveat: some portals void the rebate when a code is applied — verify the order tracks. (Rate not verified in this brief.)

### Who Qualifies

### How To Redeem Online
1. Go to Lulus.com/military-discount (or the Lulus app) and start the Beans iD verification widget.
2. Create or sign in to your **Beans iD** account and verify your military status.
3. Receive your **one-time discount code** from Beans iD.
4. Add items to your bag on Lulus.com or the app and enter the code at checkout. (No in-store option — Lulus is online only.)

### How Verification Works
Verification runs through **The Beans Group (Beans iD)**, operated by Pion (Student Beans). You create a free Beans iD account and confirm eligibility; Lulus notes you're providing personal information to Beans iD and that Lulus doesn't control their privacy practices — review Beans iD's Terms and Privacy Policy. Each issued code is single-use and tied to your account. Re-verification cadence is set by Beans iD, not stated on Lulus's page.

- **Online only** — valid on Lulus.com or the Lulus app; no in-store redemption.
- **Cannot be combined** with any other offer or promo code.
- **One-time use** per code; **not transferable**; valid only for the Beans iD account holder it was sent to.
- **No minimum purchase.**

### FAQ
#### Does Lulus offer a military discount?
Yes. Lulus offers **10% off** to military/armed-forces members verified through The Beans Group (Beans iD), valid online on Lulus.com or the Lulus app.

#### How much is the Lulus military discount?
**10% off.** There is no published higher tier — "up to 25%" or "30%" figures on coupon sites are not supported by Lulus's own terms.

#### Do veterans, spouses, or dependents qualify?
Lulus's terms say only "military/armed forces members verified through The Beans Group." Whether veterans, reserve/Guard, retirees, or dependents/spouses qualify is **determined by Beans iD's verification**, not spelled out on Lulus's page — check your status directly in the Beans iD flow.

#### How do I verify my status?
Through a free **Beans iD** account. Verify once, then use the one-time code Beans iD issues at Lulus checkout.

#### Does Lulus use ID.me, GovX, SheerID, WeSalute, or VerifyPass?
No. Lulus uses **The Beans Group (Beans iD)**. Claims that it uses ID.me or SheerID are incorrect.

#### Can I use it in stores or online?
**Online only** — Lulus.com or the Lulus app. Lulus is a direct-to-consumer online retailer; there is no in-store military discount.

#### What is excluded?
Gift cards, beauty & wellness items, and previous purchases. US only, one-time-use code, no stacking.

#### Can I combine it with promo codes or sale items?
No — the code **cannot be combined with any other offer**. It has no minimum, but you can't stack it with the 15% text-signup offer or other promo codes.

#### What's actually the cheapest way for a service member to buy from Lulus?
For a **first order**, the 15% text-signup offer saves more than the 10% military code. For a **repeat full-price order**, use the 10% military code plus a cashback portal. On sale/markdown items, the public markdown usually wins.

#### Does Lulus offer a first responder, teacher, nurse, government, or student discount?
Lulus offers a **healthcare (10%)** discount and a **student** discount through the same Beans iD portal, and lists first-responder/teacher/parent categories on Beans iD. Values beyond the verified 10% healthcare tier weren't confirmed in this brief.
