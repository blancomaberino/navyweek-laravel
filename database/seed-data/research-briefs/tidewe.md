# TideWe — Military Discount & Maximum-Savings Brief

**Researched:** July 20, 2026 · **Baseline cart for all math:** one **$200 TideWe order** (e.g. a pair of insulated chest waders plus a pair of rubber hunting boots).

## Headline finding

**TideWe offers a genuine, standing military discount — 15% off — verified through GovX ID, and it is open to a wide "hero" audience, not just active-duty troops.** TideWe's own military page confirms verification runs entirely through **GovX ID** (its FAQ is all about GovX). Reported eligibility covers active duty, veterans, spouses and dependents, plus first responders (law enforcement, EMS, fire). The catch is stacking: TideWe is a heavy discounter whose public flash sales and member pricing are frequently deeper than 15%, and the GovX code generally will not stack on already-marked-down items — so on this hunting-gear brand the sale is often the better deal than the badge. Archetype: **Shopify DTC outdoor brand running a GovX ID "verified hero" 15% code layered on top of aggressive baseline discounting.**

## Stacking Rules (verified, both brand + portal terms)
1. GovX ID issues a single-use discount code; standard GovX integrations apply **one code per order** and commonly **exclude sale/clearance** items — so the 15% usually will **not** stack on Flash Sale pricing.
2. TideWe's **member "subscribe 10% off"** and member-exclusive pricing are separate account perks; treat them as an alternative, not a guaranteed stack with the military code.
3. Verification is per-person via GovX ID (free, real-time); the code is tied to the verified account.
