## Headline finding

Sun Home Saunas has a **real, official, brand-published military discount: $300 off saunas and cold plunges**, verified through a **GovX form** on the brand's own page — the code arrives within 5–10 minutes and is single-use (you can re-verify for a new code per order). Unusually for this category, the brand's terms state the code **stacks on top of hard-marked sitewide sale prices** (it just can't combine with another coupon code), so the best military path is sale price − $300. The genuinely biggest lever, however, is not the military discount at all: **HSA/FSA payment via Truemed**, which the brand promotes as 30–40% effective pre-tax savings on saunas and cold plunges — worth ~$1,800–$2,400 on the baseline cart versus $300 from the military code. Archetype: **E — identity discount with no stacking game beyond it** (no cashback portal, no GovX marketplace storefront, no ExpertVoice, no exchange path), with the HSA/FSA payment rail as the overlooked bigger sibling offer.

## Stacking Rules (verified, brand terms; no portal exists)
1. **The $300 military code stacks on hard-marked sitewide sale prices.** Verbatim: "Site-wide seasonal sales (hard-marked discounts) may stack with one coupon code per order." This is the page's most valuable verified fact — most wellness brands force full price.
2. **Only one coupon code per order.** The military code cannot combine with any other code or promotional offer — so it's either the $300 code or the welcome/signup code, never both.
3. **Codes are single-use, personal, non-transferable** — but the FAQ explicitly allows returning to the GovX form to generate a new code for each additional order, with "no limit on how many codes you can request."
4. **No cashback layer exists to void** — Sun Home is on no major portal (Rakuten and TopCashback both 404), so there's no portal-tracking trap to warn about.
5. **HSA/FSA (Truemed) is a payment method, not a coupon** — brand instructions: check out as Guest (not Shop Pay) and select Truemed. Whether a discount code can be applied on the same order is **not stated anywhere**; flag as unverified, recommend readers confirm with support (info@sunhomesaunas.com / 1-844-728-6200).
6. **Do not publish codes.** Brand terms prohibit codes being "shared, sold, or published on third-party coupon sites" — the NavyWeek page must link to the brand's verification page, never paste a code.
