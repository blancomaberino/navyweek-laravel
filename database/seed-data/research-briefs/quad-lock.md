# Quad Lock — Military Discount & Maximum-Savings Brief

**Researched:** July 14, 2026 · **Baseline cart for all math:** one ~$120 Quad Lock motorcycle starter setup (iPhone case ~$40 + handlebar/stem mount ~$60 + weatherproof wireless charging head or poncho ~$20), bought at quadlockcase.com. US, before tax/shipping (free US shipping over $50).

## Headline finding

Quad Lock **does** run an official military discount, but it is **manual and the percentage is not published.** Per Quad Lock's own support article, you email a photo of your Military ID or Statement of Service to Customer Support and they issue a one-off discount code for online purchases — there is no ID.me/GovX/SheerID checkout and no stated %. The "10%–25% military discount" that coupon sites advertise is **fabricated/conflated** with Quad Lock's public 10% newsletter code; do not repeat it as fact. Quad Lock almost never discounts sitewide, so the single biggest lever for everyone — verified or not — is the **annual Black Friday 30% off sitewide** sale (Nov 2025 ran ~Nov 13–Dec 2). Archetype: **J (manual/discretionary email discount)** crossed with **C (the once-a-year sale beats the discount and won't stack with it)**. Best move: if you need it now, use the free 10% newsletter code (or ask Support what the current military code is worth); if you can wait until late November, the 30% sale beats any code.

## Stacking Rules (verified, both brand + portal terms)
1. **One code per order.** Quad Lock checkout takes a single discount code, so the military code and the newsletter code **cannot combine** — they're mutually exclusive.
2. **The 30% Black Friday sale is a storewide price cut, not a code**, and Quad Lock has not historically layered an additional military code on top; the sale price is the floor. During Black Friday, the sale > any code, so buy the public price.
3. **Cashback + a checkout code usually don't stack.** Rakuten/TopCashback terms commonly void or reduce cashback when a non-portal code is applied; a manually issued military code is exactly the kind that breaks tracking. Use *either* a portal (no code) *or* a code, not both.
4. **No third-party marketplace stack.** No GovX store exists, so there's no member-price channel to compare or combine.

### FAQ

#### Does Quad Lock offer a military discount?
Yes. Quad Lock says it "proudly supports Military personnel with a discount for online purchases." You claim it by emailing a photo of your Military ID or Statement of Service to Customer Support, who then send you a discount code.

#### How much is the Quad Lock military discount?
Quad Lock does **not publish the percentage.** The "10%–25%" figures on coupon sites are unverified (and appear conflated with Quad Lock's public 10% newsletter code). Ask Support what your code is worth before you buy.

#### Do veterans, spouses, or dependents qualify?
Quad Lock only says "Military personnel," verified by Military ID or Statement of Service. Veterans with a valid military/retiree ID may qualify, but Quad Lock does not explicitly list veterans, spouses, or dependents — confirm with Support rather than assuming.

#### How do I verify my status?
Email a photo of your Military ID or Statement of Service to Quad Lock Customer Support via the "contact us" link in their military-discount support article. It's a manual review; there's no automated verifier.

#### Does Quad Lock use ID.me, GovX, SheerID, or WeSalute?
No. Quad Lock verifies **manually by email**. There is no ID.me/GovX/SheerID checkout, and no Quad Lock storefront on GovX.

#### Can I use the discount in stores or only online?
Online only — Quad Lock sells direct at quadlockcase.com, and the discount is for online purchases.

#### What's excluded?
Quad Lock doesn't publish exclusions. It's a single code per order, so it won't combine with the newsletter code or the Black Friday sale. Confirm any product/category limits with Support.

#### Can I combine it with promo codes or the sale?
No. Checkout accepts one code per order, and the Black Friday 30% sale is a storewide price cut that the military code has not historically stacked on. Pick the single best price.

#### What's actually the cheapest way for a service member to buy from Quad Lock?
If Black Friday is live, buy the **30% off sitewide** sale — it beats every code and needs no verification. Otherwise, use the free **10% newsletter code**, or email Support for a military code and take whichever is larger. Only use a cashback portal when you're *not* applying a code.

#### Does Quad Lock offer a first responder, teacher, nurse, or student discount?
No dedicated Quad Lock program was found for these groups. Third-party retailer **Tackform** offers 15% to military, first responders, teachers, and government employees on the Quad Lock items it stocks.

#### Does Quad Lock run a Veterans Day or Memorial Day sale?
No dedicated Quad Lock-run military-holiday sale was found. Its signature event is **Black Friday** (30% off sitewide in 2025).
