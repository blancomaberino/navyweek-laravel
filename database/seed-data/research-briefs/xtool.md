# xTool — Military Discount & Maximum-Savings Brief

**Researched:** July 20, 2026 · **Baseline cart for all math:** one $1,299 xTool machine (e.g., a mid-tier laser/engraver bundle).

## Headline finding

xTool runs an official but **shallow** military discount: **5% off** for a broad eligibility set (active-duty military, veterans, retirees, police, fire, EMT, government employees, healthcare workers, teachers Pre‑K through professor, and university students), verified through **VerifyPass**. The code is one-time use with re-verification required for each purchase, no minimum spend, and it cannot be combined with other promo codes. Because xTool runs frequent large public promotions and bundle deals that routinely beat 5%, the 5% code is usually only the winner when no better public promo is live. The under-appreciated lever for machine owners is the **Trade Up program** ($50–$800 credit toward a new machine), which can dwarf the 5%.

## Stacking Rules (verified, both brand + portal terms)
1. The 5% VerifyPass code **cannot be combined with other promo codes** — one code per order.
2. The code is **one-time use** and requires **re-verification for every purchase**; no minimum spend.
3. Because it doesn't stack on public promos, treat 5% vs. the live public sale as an **either/or** — pick the bigger.
4. Trade Up credit is a separate mechanism applied to the machine price; confirm whether a promo code can sit on top of a Trade Up order at checkout.
