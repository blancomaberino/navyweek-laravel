# Ten Thousand — Military Discount & Maximum-Savings Brief

**Researched:** July 11, 2026 · **Baseline cart for all math:** one $58 pair of Interval Shorts (5", no liner). (Free shipping kicks in at $150+, so a single pair carries shipping — noted where it changes the ranking.)

## Headline finding

Ten Thousand runs a **real, official 25% off** military and first-responder discount, verified through **GovX ID** and redeemed on tenthousand.cc as a single-use code (one code per day). This is a genuine, generous everyday discount — better than most apparel brands' 10–15%. But it is **not** the cheapest path when Ten Thousand's twice-yearly **Surplus Sale** is live: that public sale runs up to 40% (occasionally deeper on legacy styles), covers the best-selling Interval Short, and beats the verified 25% on any item it includes. Archetype: **E (multi-tier identity discount, verified, no stacking game)** with a strong secondary **C (the sale beats the discount during Surplus Sale windows)**. Debunk note: aggregators list a "10% via ID.me" Ten Thousand offer — the brand's own program is 25% via **GovX**, and ID.me's store page shows **no active Ten Thousand military offer** as of July 11, 2026.

## Stacking Rules (verified, both brand + portal terms)
1. **GovX 25% is a single-use code, one per day** — the brand states you log in with GovX ID to unlock a new code per purchase. It functions as its own discount and **cannot be combined with another promo code** in the same order.
2. **GovX code excludes packs, kits, and limited edition gear** (verbatim brand exclusion).
3. **The 15% email-signup code cannot be combined with other promo codes** (new customers only) — so it does not stack on the GovX code either; it's an either/or.
4. **Surplus Sale items are final sale** (no returns/exchanges, no Quality Guarantee). Whether the GovX single-use code applies on top of already-reduced Surplus Sale items is **not stated in the official source** — treat as excluded (identity codes normally don't apply to clearance) and flag. During a sale, the public sale price is usually the play regardless.
5. **Cashback + code:** the 15% email code is a standard sitewide newsletter code and is generally **portal-safe** for Rakuten's 2%. The **GovX identity-gated code likely breaks Rakuten tracking** (verified/gated checkouts commonly void cashback) — do not assume GovX 25% + Rakuten stacks. (Rakuten rate 2% as of July 11, 2026.)

### How Verification Works
Verification is handled by **GovX ID** — a third-party identity service for military and first responders. It's real-time; you may create/log into a GovX ID account and receive a single-use code per purchase (one per day). Re-verification is per-purchase via login, not a permanent code. If verification fails, use GovX's support path. This is no more permanent than a per-purchase single-use code — each order needs a fresh code.
