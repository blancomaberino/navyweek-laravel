# Feetures — Military Discount & Maximum-Savings Brief

**Researched:** July 15, 2026 · **Baseline cart for all math:** one **$60 Feetures sock order** (e.g., three to four pairs of performance socks), compared against every discounted path a service member can use.

## Headline finding

**Feetures does offer a military discount — 10% off for all military service members — but it's a manual, email-based discount, not a verification-portal offer.** Per Feetures' own FAQ: "we are proud to offer all military service members 10% off their order," redeemed by emailing **hello@feetures.com** for a code. There is **no published first-responder, nurse, teacher, or student discount**, and Feetures does **not** run the "20% via VerifyPass" program that several coupon aggregators claim. Because Feetures allows **only one coupon per order**, the 10% competes with — rather than stacks on — better public offers: the **15%-off welcome code** for first orders, **bundle pricing up to ~15% off**, and the **Perfect Pair Rewards** loyalty program. Archetype: **small-percentage, email-gated military discount on a frequently-bundled apparel brand** — the 10% is real but often loses to the welcome code or bundles, since none of them stack.

## Stacking Rules (verified)
1. **One coupon per order.** The 10% military code, the 15% welcome code, and any other code are **mutually exclusive** — pick the biggest single one.
2. **The military discount is email-issued** (hello@feetures.com), not a self-serve portal — request it before checkout.
3. **Bundle pricing is a built-in "sale,"** so a code may or may not apply on top — confirm at checkout given the one-coupon rule.
4. **Perfect Pair Rewards** points accrue regardless of the code used, so loyalty is the one layer that effectively "stacks" over time.
5. **Cashback portals** can apply to a plain feetures.com order, but pairing them with an email-issued code may void tracking — don't assume "10% + Rakuten."
