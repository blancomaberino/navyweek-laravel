# Leatherman — Military Discount & Maximum-Savings Brief

**Researched:** July 6, 2026 · **Baseline cart for all math:** one Leatherman Wave+ multi-tool (~$110 MSRP).

## Headline finding

Leatherman runs a real, official **20% off multi-tools** for active-duty, reserve, veteran and retired US military, verified through **VerifyPass** (a one-time code, limit 3 tools per order, 1 code per person per 365 days). But for many shoppers the bigger win is **GovX** (a free-to-join military/gov marketplace advertising **25–50% off MSRP** on tactical/lifestyle brands including Leatherman) or Leatherman's own **seasonal sale (currently 20–50% off select items)** — and during a deep sale the public price can beat the non-combinable 20% code. Archetype: **real discount + a marketplace substitute (GovX) that often wins**, with a separate 40% "special discounts" tier for other communities.

> **Debunk line:** Aggregators blur Leatherman's tiers. The **military** discount is **20% off multi-tools** (VerifyPass), **not** the "40% off" figure some sites cite — that 40% appears in community reports tied to Leatherman's **other** special-discount communities (first responders / medical / teachers / students), not the military tier. Also note the code is **on-site only, non-combinable, excludes apparel and limited editions, and is capped at 3 tools/order** — claims of a stackable sitewide military code are false.

## Stacking Rules (verified, both brand + portal terms)
1. The military 20% code **cannot be combined with any other offer** and can't apply to sale items alongside the sale — so during a 20–50% sale you take the sale, not the code. (Source: leatherman.com military-discount terms.)
2. Code is **one-time use, on www.leatherman.com only**, capped at **3 discounted tools per order**, 1 code per person per **365 days**, expiring **Dec 31**. (Source: same.)
3. **GovX is a separate marketplace, not a stack** — you buy on GovX at its member price; you can't add the leatherman.com military code or a cashback portal on top. (Source: govx.com brand page.)
4. **Excludes gift cards, limited editions, apparel.** Applies to "original multi-tool price and custom add-on features only." (Source: leatherman.com military-discount.)
5. No cashback-portal figure is published for leatherman.com; a VerifyPass identity-gated checkout typically breaks portal tracking, so don't rely on a portal stacking here.

4. Add multi-tools to cart (max 3 discounted tools per order) and enter the code in the "discount code" box at checkout.

### FAQ
#### Does Leatherman offer a military discount?
Yes — 20% off multi-tools, verified via VerifyPass, on leatherman.com.

#### How much is the Leatherman military discount?
**20% off multi-tools** (original price + custom add-ons). Not the "40%" some sites cite — that's a different community tier.

#### Do veterans, retirees, and reserve qualify?
Yes — active duty, reserve, veteran and retired members of any US military branch. Spouses/dependents aren't listed on the military page.

#### How do I verify my status?
Through **VerifyPass**, from the Leatherman military-discount page — you get a one-time code.

#### Does Leatherman use ID.me, GovX, SheerID, or VerifyPass?
The on-site military discount uses **VerifyPass**. **GovX** is a separate marketplace that also carries Leatherman.

#### Can I use it in stores or online?
Online only, at www.leatherman.com.

#### What is excluded?
Gift cards, limited edition items, and apparel; sale items can't take the code (non-combinable). Max 3 discounted tools per order.

#### Can I combine it with promo codes or sale items?
No — the code cannot be combined with any other offer. During a deep public sale, take the sale instead.

#### What's actually the cheapest way for a service member to buy a Leatherman?
Compare three prices: the public sale, the GovX marketplace price, and the 20% VerifyPass code — buy the lowest. During 30%+ sales the public price usually wins; GovX can beat both on some tools.

#### Can I buy Leatherman through GovX?
Yes — GovX offers a free lifetime military/gov membership and lists Leatherman; check the specific tool's price after login and note stricter marketplace returns.
