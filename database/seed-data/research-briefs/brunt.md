## Headline finding

BRUNT Workwear (bruntworkwear.com) has a **real, brand-run 10% military discount, verified through ID.me** — stated on BRUNT's own Help Center "Military & Veteran Discount" page. BRUNT names the eligible groups as **active-duty military, veterans, and first responders**, and it applies to "all BRUNT gear." You click the **ID.me** button at checkout (it sits just below the discount-code/gift-card box), verify once, and the 10% applies automatically with no email-approval wait. That's the honest everyday answer and, for a full-price BRUNT order, the best standing route.

The catch is BRUNT's own rule: **"Our system allows for one discount code per order."** The ID.me 10% is that one discount — so it **won't stack** with a promo code, a first-order welcome code, or (per the "one code" limit) a public sale code. BRUNT is a direct-to-consumer trade brand that **runs frequent seasonal sales and gift-with-purchase promos** (Memorial Day, July 4, Black Friday), and it hands new customers a **$10-off-first-order** email code or a **$5-off-$100** SMS code. Because none of those combine with the 10%, the shopper's job is to pick the single lowest path. Archetype: **E — single-tier identity discount via ID.me** (the verified discount basically *is* the standing savings path, no code/cashback stacking game), with a **C** flavor (BRUNT's own seasonal sales + welcome code can rival the 10% on a first order, and the two can't combine). Ignore the coupon-site claims of "**up to 40% off military**," "30% off," and "45% off" — the only verified military figure BRUNT publishes is **10% via ID.me**, and there is **no GovX BRUNT storefront** this pass.
