## Stacking Rules (verified, both brand + portal terms)
1. **The GovX ID code is single-use and one-at-a-time** — a fresh code requires re-verification (limit reported at ~1 per 24 hours; unused codes are re-issued, not duplicated). It is a standard Shopify discount code: the checkout accepts **one code**, so it cannot combine with a rewards-redemption code or any public promo code.
2. **GovX code + cashback do NOT stack:** Swagbucks (6%, as of July 13, 2026) voids earnings on "promo codes not found on Swagbucks" — a GX code kills the cashback. Take the 10% code over 6% cashback; never plan on both.
3. **Subscription pricing (5%→15%) is automatic**, not a code — whether a GovX code applies **on top of** a subscription order is **not stated** anywhere official. Aggregators claim promo codes generally don't apply to subscription orders. **Unverified — builders must not assert it either way.**
4. **ALP Rewards:** one rewards discount code per order (ALP's own FAQ); you cannot redeem a points code and a free-product code together, and by the one-code checkout rule a rewards code and a GovX code are mutually exclusive on the same order. Points *earning* on discounted orders is not stated.
5. **Northerner's GovX 10% is a separate verification and a separate storefront** — it does not interact with alppouch.com offers. Its stated exclusion: government contractors ineligible. Whether it stacks with Northerner/Nicokick welcome offers is not stated — assume one offer.
6. **Free shipping $80+** applies after discounts on the direct site — a 20-pack at $89.96 still ships free; a discounted 5-pack does not.

Codes can't be shared (single-use, GX prefix), and a new code is limited to about one per 24 hours per GovX's documentation. If verification fails, GovX support handles review. Separately, age verification (21+) applies to everyone at site access and purchase.

### FAQ

#### Does ALP offer a military discount?
Yes. ALP partners with GovX to give verified military, veterans, military spouses and dependents, first responders, and government employees a discount at alppouch.com.

#### How much is the ALP military discount?
10%. The site's button says "save up to 10%," but the offer is configured as a flat 10% off your order via a single-use GovX code.

#### Do veterans, spouses, or dependents qualify?
Yes — the offer explicitly covers current and former U.S. military, and military spouses and dependents. All buyers must be 21+.

#### How do I verify my status with ALP?
Through GovX ID on alppouch.com/pages/service-discounts: create a free GovX account, verify (usually in seconds), and a single-use discount code is issued for your order.

#### Does ALP use ID.me, GovX, SheerID, or WeSalute?
GovX (GovX ID) only. There is no ID.me, SheerID, or WeSalute offer for ALP, and ALP is not sold on the GovX marketplace itself.

#### Can I use it in stores or online?
Online only, at alppouch.com. ALP tins sold at convenience stores have no military discount mechanism.

#### Can I combine it with promo codes, rewards, or cashback?
No. Checkout takes one code, so the GovX code can't combine with rewards or promo codes, and Swagbucks cashback is voided by non-Swagbucks codes. Whether it applies to discounted Subscribe & Save orders is unconfirmed.

#### What's actually the cheapest way to buy ALP?
Per can: Nicokick/Northerner volume tiers ($3.99–$4.69/can) plus Nicokick's 20% first-order newsletter code or Northerner's own 10% GovX discount usually beat alppouch.com. Buying direct: Subscribe & Save's 15% top tier edges out the flat GovX 10%.

#### Does ALP offer a first responder, government, teacher, nurse, or student discount?
First responders (law enforcement, fire, EMS) and federal/state/local government employees — yes, same 10% GovX offer. Teachers, nurses, and students are not listed in ALP's offer (Northerner's GovX offer does include medical staff and teachers).

#### Does ALP run a Veterans Day sale?
In 2025 ALP ran a Veterans Day promotion (a free tactical holster with $100+ purchase, tied to its GovX partnership). Historical only — not a promised annual event.
