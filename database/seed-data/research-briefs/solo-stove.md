## Stacking Rules (verified, brand + portal terms)
1. **The $20 (and $15) code is one-time and non-combinable with any other *promotional code*** — VerifyPass states this verbatim for every tier. You cannot enter the Hero code and a public promo code on the same order.
2. **Automatic sale prices are not "codes."** Solo Stove's seasonal markdowns and "Steals" show as the product price, so the $20 code *may* apply on top of an auto-discounted item — but **clearance/final-sale/last-chance items are typically excluded**, and this is not documented, so **verify at checkout** (Medium confidence).
3. **$100 minimum spend** applies to every tier — carts under $100 can't use the code (the Bonfire 2.0 at $259.99 clears it easily).
4. **Cashback + the Hero code usually don't stack.** Using a coupon/verified code commonly voids or reduces portal cashback (Rakuten/ID.me Shop terms), and a code-based checkout can break tracking. Use cashback on a **no-code** order; don't assume "code + Rakuten."
5. **GovX marketplace and ExpertVoice are closed substitute storefronts** — their member price is the price; no brand code or cashback stacks on top.
6. **Eligibility is per-channel:** VerifyPass covers military/veteran/family + the professional tiers; ExpertVoice is outdoor-industry-only. Don't conflate them.
