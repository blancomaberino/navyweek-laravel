Nectar is a **near-permanent-sale mattress DTC** archetype: the sale is the real discount and it is available to everyone; verified service members simply shave another 5% on top. Best path for most: **buy during a deep sale (July 4/Black Friday) and add the verified 5%**; effective Queen ≈ **$664**.

## Stacking Rules (verified, brand terms)
1. **The 5% stacks ON the sale.** The offer is worded "an extra 5% off **our best onsite offer**" — the current sale price is the base it applies to. This is the atypical, favorable case for a mattress brand (most exclude sale items). **High confidence** from the brand pages' own wording.
2. **The 5% does NOT stack with other promo codes.** "Cannot be combined with any other offer"; the code is treated as separate from standard promo codes, so you use *either* the verified 5% code *or* a public promo code, not both.
3. **Merchandise only.** Excludes shipping & handling, taxes, and packaging. One-time-use online code.
4. **No price adjustments / full-price boilerplate caveat.** The military page also carries legacy "valid on full-price merchandise only" language that conflicts with "extra 5% off best onsite offer." Treat the *on-sale-plus-5%* mechanic as controlling (it matches all three offer pages and shopper reports) but **verify the code applies to the sale price at checkout** before ordering.
5. **Rakuten cashback likely voids with the military code.** Rakuten's terms: "codes not listed on Rakuten may void Cash Back." The verified 5% is a non-Rakuten, identity-gated code — so **military 5% + Rakuten is not a reliable stack**. Pick one.
6. **GovX is a closed substitute**, not a stack — you cannot add a Nectar on-site code or a cashback portal on a GovX checkout; compare its net price to sale−5%.
