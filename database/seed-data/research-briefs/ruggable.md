Because Ruggable states its codes **can't be combined**, the game is picking the single deepest available offer, not stacking. Archetype: **direct-to-consumer home-goods brand with no military discount — save via welcome code + sale events + cashback.**

## Stacking Rules (verified, brand terms)
1. **Ruggable codes cannot be combined** with other promo codes — it's one code per order, so "stacking" a welcome + referral doesn't work.
2. **Sitewide sale pricing generally replaces code discounts** — you take the sale or a code, not both; the live "up to 30%" event is stated as applying with no exclusions but still won't combine with a separate code.
3. **Cashback portals require a no-code, portal-tracked order** — adding a Ruggable code can reduce/void the cashback; the two rarely stack cleanly.
4. **Trade pricing is its own program** (approved pros) — not combinable with public codes.
5. **Price protection (7 days)** lets you claim a one-time adjustment if your item drops after purchase — a legitimate way to "catch" a sale you just missed.
