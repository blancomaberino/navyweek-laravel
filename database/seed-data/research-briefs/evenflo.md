# Evenflo — Military Discount & Maximum-Savings Brief

**Researched:** July 14, 2026 · **Baseline cart for all math:** one Evenflo Revolve360 rotating convertible car seat, ~$399.99 MSRP on evenflo.com (illustrative; prices vary by model and season).

## Headline finding

Evenflo runs a **real, first-party 20% military/veteran discount** on evenflo.com through its **Community Heroes** program, verified via **ID.me**. It is not military-exclusive — the same 20% goes to first responders, healthcare workers, teachers, and students. Active duty, dependents, veterans, reservists, and the National Guard all qualify. This is the archetype-**E** pattern (a brand-run identity discount that basically *is* the savings path, since Evenflo runs no public coupon codes and isn't on cashback portals) with a strong secondary **L** angle: **both AAFES (shopmyexchange.com) and the Navy Exchange (mynavyexchange.com) stock Evenflo car seats tax-free**, which can beat the on-site 20% once you factor sales tax and MILITARY STAR financing. Two honest caveats: (1) Evenflo's own **Promotions page tile says "15%"** while every group-specific offer page (military, first-responder, student, medical) advertises **"20% OFF"** — a live discrepancy on Evenflo's own site; verify the exact code value in the ID.me widget before quoting. (2) The **"25% Evenflo military discount"** that aggregators repeat is a **historical Veterans Day promo** (e.g., 25% sitewide Nov 9–16, 2023), not the everyday rate.

## Stacking Rules (verified, both brand + portal terms)
1. **The 20% is delivered as a promo code** ("Get your promo code today!") after ID.me verification — a single code entered at checkout.
2. **Stacking of the ID.me code with sales, Outlet, or other promo codes is NOT stated** in Evenflo's official sources. Shopify stores typically allow only one discount code per order, so **assume it does not stack** with Outlet/clearance or another code until the ID.me widget confirms otherwise.
3. **The Exchange is a separate storefront** — you buy at the exchange's own (tax-free) price; you cannot add the evenflo.com ID.me code on top.
4. **No cashback layer exists** — Evenflo is not listed on Rakuten/TopCashback/RebatesMe, so there's no portal to stack or void.
5. **Community-reported "status stacks with seasonal sales for 30–40%"** is **unverified** (aggregator/community claim) — do not present as fact; the official pages don't confirm any stack.
