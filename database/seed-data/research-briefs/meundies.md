## Stacking Rules (verified, both brand + portal terms)
1. **One promo code per order** (MeUndies help center). You cannot stack two codes.
2. **Promo codes do NOT apply to membership or monthly subscription orders** — those are placed automatically at VIP pricing (MeUndies help center).
3. **Member (VIP) pricing is automatic and is not a code** — you generally can't stack an additional public promo code on top of the 30% member price.
4. **Cashback portals void on off-portal codes.** Rakuten (and TopCashback/BeFrugal) reduce or void cashback when a non-portal coupon code is used. So "welcome code + Rakuten" is NOT a valid stack — it's either/or.
5. **Public sitewide sales (e.g., 50% off) apply without a code and are portal-safe** — this is why the seasonal sale + cashback is the best true stack.
6. **Pack 'N Save is built-in bundle pricing, not a code** — portal-safe; layer cashback under it.
