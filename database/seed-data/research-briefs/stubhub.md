# StubHub Military & Veteran Discount Page Brief

## Executive Summary

StubHub does offer a military/service-member discount, but only through its verification partner **GOVX** — there is no StubHub-issued percentage-off code applied directly on the site. Verified GOVX members (military, first responders, law enforcement, medical service providers, educators, and other government employees) can claim a **single-use code worth $20 off a ticket order of $200 or more**, redeemable only at StubHub.com by entering the code in the **Gift cards** field at checkout. The code is not automatically applied, cannot be added retroactively, and expires (expiration shown on the GOVX StubHub page). The single most important caveat: this is a flat $20 minimum-spend offer, not an everyday percentage discount, and it must be applied as a "gift card" before submitting the order. (Separately, ID.me Shop lists "up to 5% cash back" on StubHub, but that is an ID.me Shop affiliate rebate, not a StubHub discount — see Verified Facts.)

### How To Redeem Online
1. Create a GOVX account and verify your eligibility with the required documentation.
2. Go to the GOVX StubHub page, select the available discount, and copy the discount code from the pop-up.
3. On StubHub.com, select "Use your code" and find your tickets ($200+ order required).
4. At checkout, under "Gift cards," select "Manage," add the code, and check the box to apply it to your eligible order.
5. Confirm the discount appears before submitting — codes cannot be applied retroactively.

### How To Redeem In Store
Not applicable. StubHub is an online ticket marketplace; the GOVX discount is redeemable only at StubHub.com. There is no in-store/register redemption.

### How Verification Works
Verification is handled by GOVX, not StubHub. You register a GOVX account and provide documentation to prove eligibility (military, first responder, law enforcement, medical, education, or government). Once GOVX approves you, you can claim the StubHub code from the GOVX StubHub page. The discount code is single use and has an expiration date shown in the "About StubHub" section of the GOVX StubHub page. Re-verification frequency for the GOVX account itself is not stated on StubHub's page — check GOVX for its account/verification renewal terms. For redemption issues, StubHub directs users to its support; for eligibility/verification issues, contact GOVX support.
